## Signal 1: Driftwood — Zero-Copy GPU Inference via WebAssembly on Apple Silicon

**Source:** Hacker News, abacusnoir.com (April 18, 2026)

A developer has published **Driftwood** — a system demonstrating that on Apple Silicon, a WebAssembly module's linear memory can be shared directly with the GPU with **zero copies**. The CPU and GPU read and write the same physical bytes in unified memory.

**How it works (three-link chain):**
1. `mmap` with `MAP_ANON | MAP_PRIVATE` returns a 16KB-page-aligned memory region
2. Metal's `MTLDevice.makeBuffer(bytesNoCopy:length:)` wraps that pointer as a GPU-accessible buffer — no copy on Apple Silicon's unified memory architecture
3. Wasmtime's `MemoryCreator` trait lets you provide your own backing memory, so the Wasm linear memory IS the mmap region IS the Metal buffer

**Measurements:**
- Pointer identity confirmed: mmap address == MTLBuffer.contents() address
- RSS delta: 0.03 MB (zero-copy) vs 16.78 MB (explicit copy path)
- GEMM latency: ~6.75ms either way (compute identical on UMA; the win is memory overhead, not compute speed)

**Why this matters for Alizé:**

1. **Local AI inference on consumer hardware becomes viable.** Wasm + Metal + Apple Silicon = a portable, sandboxed inference runtime that doesn't need cloud GPU APIs. For SMBs with data sovereignty concerns (a real French market concern given CNIL/GDPR sensitivity), this could enable fully local AI agent deployments without specialized hardware.

2. **Edge deployment pattern.** If Driftwood matures, the "AI agent" could run entirely in the browser or on a local Mac. This creates a new deployment topology — centralized orchestration, distributed execution — that changes governance requirements. Alizé's audit/oversight layer would need to support agents running across heterogeneous edge environments.

3. **Wasm as a deployment unit for AI is no longer theoretical.** The isolation guarantees of Wasm (sandbox, deterministic, portable) combined with GPU compute via Metal is a real stack. This could become a standard way to package and distribute AI agent capabilities.

3. **Enterprise pricing trajectory is becoming visible.** High consumption at research preview pricing suggests the eventual enterprise tier will be expensive. Multi-agent, multi-tool governance (tracking spend across Claude Design, Claude Code, Cursor, etc.) becomes a CFO concern.
