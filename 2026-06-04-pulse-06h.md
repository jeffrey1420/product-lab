## Signal: Agentic.ai Published Comprehensive Agentic AI Scoring Framework (June 4, 2026)

agentic.ai published an updated "What Is Agentic AI" guide today (June 4, 2026), backed by 282 tools scored across 32 categories. Key takeaways:

**The core distinction — agentic vs chatbot vs copilot:**
| Capability | Chatbot | Copilot | Agentic AI |
|-----------|---------|---------|------------|
| Generates text/code | Yes | Yes | Yes |
| Calls external APIs | No | Limited | Yes |
| Plans multi-step work | No | Limited | Yes |
| Executes without per-step approval | No | No | Yes |
| Recovers from errors | No | No | Yes |
| Knows when task is done | No | No | Yes |

**Eight dimensions of agenticness (0-4 each, total 0-32):**
1. Action Capability — executes real actions
2. Autonomy — chooses next steps
3. Planning & Reasoning — decomposes complex goals
4. Adaptation & Recovery — handles errors
5. State & Continuity — remembers context
6. Reliability — consistent results
7. Interoperability — works with other tools
8. Safety & Observability — guardrails and audit trails

**Six levels of agenticness:** Reactive Tool → Tool User → Assistant → Agent → Autonomous Agent → Strategic Agent

**For Alizé:** This framework validates the workflow/agent distinction from the Alizé brief. Most business workflows sit at level 1-2 (Reactive Tool / Tool User). Alizé's managed service keeps clients at level 2-3, not level 4-5 (autonomous agents) — which is exactly where governance, compliance, and predictability are achievable. This is a strong sales argument: "We keep you at the right level of autonomy — enough to be useful, not so much that you lose control."

## EU AI Act Countdown

**~59 days remaining until August 2, 2026** (high-risk AI system prohibition takes effect).

French enterprises deploying AI in Annex I critical infrastructure (energy, transport, healthcare, finance, water, public transport) must have conformity assessments and human oversight documentation complete. Market withdrawal is the penalty for non-compliance.

This is Alizé's primary commercial window. The compliance documentation requirement is real, non-negotiable, and approaching fast.
