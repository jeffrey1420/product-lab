## Mistral Forge: The Enterprise Model Customization Play

**Forge** (announced March 17, 2026) is Mistral's enterprise system for training custom AI models grounded in proprietary knowledge.

**What it does:**
- Pre-training on large internal datasets (domain-aware base models)
- Post-training for specific tasks and environments
- Reinforcement learning to align models with internal policies, evaluation criteria, operational objectives

**Early partners:** ASML, DSO National Laboratories Singapore, Ericsson, European Space Agency, HTX Singapore, Reply

**The key quote:** *"Custom models make enterprise agents reliable. Instead of relying on generic reasoning, agents powered by domain-trained models can interpret internal terminology, follow operational procedures, and understand how different systems and data sources relate to one another."*

**Strategic implication for Alizé:**
Forge is the missing piece in the sovereign stack. Alizé's workflow design + Mistral's Forge (custom training) + French data residency = a complete offer for enterprises that need AI aligned to their specific context. This is not just "use Mistral's API" — it's "build and operate a custom AI that knows your business." Alizé could position as the **Forge integration and operational partner** for mid-market French companies too small for Mistral's direct enterprise team.

## Mistral Workflows: The Orchestration Layer Is Here

**Workflows** (public preview, April 27, 2026) is Mistral's production orchestration layer — the durable, observable, fault-tolerant runtime for enterprise AI processes.

**The problem it solves:** Models work in notebooks. They fail in production — silent failures, timeout cascades, no audit trail, no human approval mechanism.

**Key features:**
- `wait_for_input()` — single line of code for human approval mid-workflow; workflow pauses, notifies reviewer, resumes exactly where it left off
- Full execution history in Studio (every step tracked, auditable)
- OpenTelemetry-native observability
- Retry logic and fault tolerance for long-running processes

**Already in production at:** ASML, ABANCA, CMA-CGM, France Travail, La Banque Postale, Moeve

**The CMA-CGM and France Travail names are significant:**
- CMA-CGM is the world's third-largest container shipping company (French)
- France Travail is the French national employment agency (700+ offices, massive administrative volume)

These are not pilot projects. They are production workloads.

**The Alizé competitive question:** Mistral Workflows is now directly competitive with what Alizé would build as its operational layer. However, Mistral's Workflows is a platform — it still requires design, integration, and ongoing operation. **Alizé's managed service value proposition is: we design the workflow, connect your systems, and run it for you.** The platform doesn't replace the service. But the messaging has to be careful — Alizé should position as a **Mistral Workflows implementation and operations partner**, not a competing platform.

## Mistral Connectors: MCP as First-Class Enterprise Integration

**Connectors** (GA, May 22, 2026) formalizes MCP as the enterprise integration primitive inside Mistral's platform.

**What changed:**
- Built-in connectors (Salesforce, GitHub, etc.) + custom MCP registration
- Once registered, a connector is a discoverable, governed, monitored tool available across Le Chat and Studio
- OAuth handling, token refresh, pagination — all packaged into the connector, not the developer's code
- Human-in-the-loop approval flows built into the connector layer
- API/SDK programmatic access for all connector operations

**The competitive insight:** MCP is now so embedded in enterprise procurement that Mistral has made it the native integration format. The question is no longer "do you support MCP?" but "how many MCP endpoints can you connect?" Alizé's MCP orchestration hub positioning (from earlier pulses) is aligned with this — but Mistral is now building it directly into their platform.

**Implication:** Alizé should document its MCP connector library as a key differentiator. "We connect your fragmented enterprise tools as MCP endpoints and orchestrate them into production workflows" maps directly to what enterprises are buying.
